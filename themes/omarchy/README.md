# Omarchy palettes

Semantic colors transcribed from the official Omarchy `quattro` branch, November 2026:
https://github.com/omacom/omarchy/tree/quattro/themes

Each JSON corresponds to `<theme>/colors.toml`. These palettes are adapted to Waybar, Rofi, Hyprland Lua and Ghostty by `scripts/desktop-theme.py`. They do not install Omarchy's Quickshell, wallpaper collections, GTK themes, or application plugins.

Additional Omarchy `colors.toml` files can be imported locally:
`~/.local/bin/desktop-theme.py --import /path/to/colors.toml --name my-theme`
Then use the theme picker or `desktop-theme.py --apply my-theme`.
